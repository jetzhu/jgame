About

Chess Playground is a free, ad-free chess site. You can play the computer, play a friend online with a share link, or play two people on one device. There are no accounts and no sign-up.

Privacy

  • No accounts, cookies, analytics or ads.
  • Your browser's local storage keeps your settings, your display name, an unfinished game against the computer or a pass & play game, private keys that let you rejoin your own online games, and the state of any online game you're hosting. None of this leaves your device except as described below.
  • Games against the computer and game analysis run entirely in your browser. Nothing is sent to the server.

How online games work

  • Player-hosted (default): the game runs in the browser of the player who created it. This server only introduces the players. When it can, your browser then connects directly to the other player's browser using WebRTC, so moves and chat don't pass through this server and the game keeps going even if the server restarts. If a direct connection isn't possible, traffic is relayed through this server without being stored.
  • Direct connections share IP addresses. To connect directly, the two browsers exchange network addresses, so the other player can see your public IP address. Your browser also asks a public STUN service (Cloudflare or Google) for that address. To avoid both, turn on Hide my IP address in Settings, and all game traffic will be relayed through this server instead.
  • Server-hosted (optional, only offered while the server is idle): the game runs on this server. Moves and chat exist only in the server's memory. They are not written to disk and disappear once a game is inactive.
